# Minimalist Pomodoro Timer

A sleek, iOS-inspired Pomodoro productivity timer featuring an "Apple liquid glass" aesthetic, fluid transitions, and built-in sound alerts.

## Features

- iOS-Inspired Glassmorphism UI: Modern backdrop filters, soft ambient gradients, and smooth tactile buttons.
- Focus & Break Modes: Seamlessly switch between 25-minute work sessions and 5-minute break periods.
- Bug-Resistant Timing Engine: Secure state-management guard clauses prevent concurrent setInterval glitches.
- Audio & Visual Alerts: Automatic session switching accompanied by an alarm tone and live-updating browser tab titles.

## Quick Start

1. Download or copy the source code into a single file named index.html.
2. Open the file in any modern web browser (Chrome, Safari, Firefox, Edge).
3. Click Start to begin your focus session!

## Built With

- HTML5
- CSS3 (Custom properties, Flexbox, Backdrop filters)
- Vanilla JavaScript (DOM manipulation, Interval lifecycle management)
